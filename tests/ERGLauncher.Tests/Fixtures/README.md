# Legacy Utf8Json fixtures

`appSettings.json` and `gameSettings.json` are generated byte snapshots of the
legacy settings schema. The generator at
`tools/LegacyUtf8JsonFixtureGenerator` uses the same `Utf8Json` 1.3.7 package,
property order, culture formatter, numeric theme value, and ignored runtime
`Icon` property as the legacy WPF format. The checked-in files are therefore
real `Utf8Json.JsonSerializer.Serialize` output, not hand-authored JSON.

From the repository root, regenerate both fixtures with:

```sh
dotnet run --project tools/LegacyUtf8JsonFixtureGenerator/LegacyUtf8JsonFixtureGenerator.csproj -- \
  tests/ERGLauncher.Tests/Fixtures
```

The generator writes the serializer's bytes directly with
`File.WriteAllBytes`; it does not pass through a text writer and does not add a
BOM or trailing newline. Verify the leading bytes and hashes with:

```sh
xxd -g1 -l3 tests/ERGLauncher.Tests/Fixtures/appSettings.json
xxd -g1 -l3 tests/ERGLauncher.Tests/Fixtures/gameSettings.json
sha256sum tests/ERGLauncher.Tests/Fixtures/*.json
```

Both `xxd` outputs must start with `7b 22` (`{"`), not the UTF-8 BOM
`ef bb bf`. Expected SHA-256 values after regeneration:

```text
4ca1069f0cef62bd67f4c43f4155225dae38acf6de7837433898e8033b292e99  appSettings.json
00d1464efdc64b802f881b03c77dfe066ac38fd4c952fc468833215379dddc6d  gameSettings.json
```

`Core/JsonCompatibilityTests.cs` reads these exact bytes and verifies that the
source-generated System.Text.Json contexts deserialize the legacy payloads and
continue to emit PascalCase keys, `Culture` as `{"Name":"..."}`, numeric enum
values, and no serialized `Item.Icon` property.
